# Sample App With @km/widgets-semlookp Widgets

# About The Project
This app was built to show and test the widgets of the [@km/widgets-semlookp](https://gitlab.zbmed.de/km/semlookp/widgets-semlookp/-/packages/) package in a real life app.


# Built With

* [ReactJS 17](https://reactjs.org/blog/2020/10/20/react-v17.html)
* [TypeScript 4.5](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-4-5.html)
* [Elastic UI](https://elastic.github.io/eui/#/)
* [@km/widgets-semlookp](https://gitlab.zbmed.de/km/semlookp/widgets-semlookp/-/packages/)
* [Create React App](https://create-react-app.dev/)
